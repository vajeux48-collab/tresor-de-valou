# Le Trésor de Valou
Site GitHub Pages sans Firebase ni base de données.

- joueur.html : prénom + code personnel + numéro d'équipe
- admin.html : réglage des équipes, génération de codes et export CSV
- index.html : redirection vers le joueur

Ouvrir admin.html, générer les codes, télécharger le CSV et distribuer un code différent à chaque invité. La répartition est équilibrée lors de la génération.

Important : aucune synchronisation entre appareils, aucune authentification administrateur, et les codes peuvent être partagés ou réutilisés.
